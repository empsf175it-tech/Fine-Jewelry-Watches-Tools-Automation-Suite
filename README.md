# ChronoForge — Fine Jewelry & Watches Tools & Automation Suite

Refined multi-page responsive front-end concept based on the project brief: a dedicated web app for Fine Jewelry & Watches Tools & Automation Suite.

## Pages
- `index.html` — Home with expanded product story, workflow sections and layered 3D motion.
- `about.html` — Product mission, principles, design language and product vision.
- `services.html` — Workflow, tools, inventory, admin and automation modules with motion-heavy sections.
- `related.html` — Client portal, analytics and integrations ecosystem.
- `contact.html` — Dummy contact details, form, social icons, FAQ and OpenStreetMap embed.
- `assets/style.css` — Shared responsive visual system.
- `assets/app.js` — Scroll progress, reveal effects, tilt/parallax, mobile menu and demo form interaction.
- `assets/favicon.svg` — 3D-style brand favicon.

## Removed
Standalone `login.html` and `signup.html` pages were removed as requested. Authentication can be added later as part of the actual application rather than the public marketing site.

## Motion
The refined version uses layered 3D orbit rings, depth, mouse parallax, card tilt, image zoom, shine sweeps, animated gradient/glow, scroll reveal, marquee motion and interactive hover states. The rotating sections are intentionally multi-layered rather than a single flat spinner.

## Images
High-resolution Pexels image URLs are used for the watchmaker, workbench and luxury-watch visuals. Replace the URLs with locally hosted assets for a production deployment if desired.

## Notes
Forms are front-end demo interactions only. The map uses an OpenStreetMap embed. Social links are visual placeholders and should be replaced with the final brand URLs.
